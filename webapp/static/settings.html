How this is protected

  • Demo-only, unchanged. The guard lives in the trading client and is not touched by this page. A real-money account is refused at connect time regardless of what is saved here.
  • Token never leaves the server. It is read from .env by the server process only. No API response contains it.
  • Atomic write. .env.tmp → fsync → rename, mode 0600. A crash mid-write cannot corrupt the file, and unrelated keys are preserved.
  • CSRF + host guard. The save endpoint requires a same-origin token and rejects any Host that is not loopback/LAN.
  • No trade bypass. Saving credentials does not place a trade. Start still runs the full risk manager.
